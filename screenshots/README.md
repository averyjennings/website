# Screenshots Directory

This directory contains screenshots of the portfolio website UI for visual feedback and validation purposes.

## Purpose

- Store screenshots of the current UI state
- Provide visual feedback to Claude Code for validating UI changes
- Document visual bugs or issues that need to be addressed
- Track the visual evolution of the project

## Usage

When you want Claude to review the UI:
1. Take a screenshot of the relevant part of the website
2. Save it in this directory with a descriptive filename (e.g., `hero-section-issue.png`, `navbar-mobile-view.png`)
3. Tell Claude to "check the screenshots" or "look at the screenshot I uploaded"
4. Claude will analyze the visual feedback and suggest fixes

## File Naming Convention

- Use descriptive names that indicate what's shown
- Include dates if tracking changes over time (e.g., `homepage-2024-01-15.png`)
- Use lowercase with hyphens for consistency

## Notes

- Screenshots are not committed to version control (add to .gitignore if needed)
- Clear out old screenshots periodically to avoid clutter
- PNG format is preferred for better quality
